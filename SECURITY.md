# Security Policy

## What's Covered/How to Report

Only use the [private vulnerability form](https://github.com/SocksTheWolf/AgenticAlert/security/advisories/new) if you have found a critical issue with the script or the website that allows for:

* escalation of privileges
* context leakage
* some other security compromise

All other issues [can be filed on the issues page](https://github.com/SocksTheWolf/AgenticAlert/issues)

### Invalid topics

Any report covering the following will be deemed invalid:

* Having to change the script to get a certain outcome
* Already having local access to the browser/machine
* Using an extension outside of the usual userscript runners
* Issues that stem from the userscript runner, rather than the script itself
