Features

You don't need to be a programmer to use AgenticAlert nor understand what it all means!

AgenticAlert has very easy to understand outputs that alerts you if something is slopcoded!

Here's a short feature list:

  • Detects over 95+ AI LLM GPT Agents (including ones you cannot block on GitHub)
  • Instantly recognizes many common slop Recomp Modules
  • Scans for over 125+ LLM file markers in a repository
  • Scans .gitignore and other GitHub metadata automatically
  • Can detect some intentional LLM poisonings
  • All processing is done locally, no external servers used
  • Automatically updates with the latest detection engine (Find something we don't detect yet? Let us know!)
  • No ads, no tracking, no bs
  • Written by hand by someone that knows what they're doing (for real)
  • Open Source!
  • Free (tips would be appreciated)
