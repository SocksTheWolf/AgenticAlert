Features

You don't need to be a programmer to use AgenticAlert nor understand what it all means!

AgenticAlert has very easy to understand outputs that alert you if something is slopcoded!

Here's a short feature list:

  • Detects over 75+ AI LLM GPT Agents (including ones you cannot block on GitHub)
  • Instantly recognizes many common slop Recomp Modules
  • Scans for over 100+ LLM file markers in a repository
  • All processing is done locally, no external servers used
  • Can detect some intentional LLM poisonings
  • Scans .gitignore and GitHub metadata without user input
  • Automatically updates with the latest ruleset
  • No ads, no tracking, no bs
  • Written by hand by someone that knows what they're doing (for real)
  • Open Source!
  • Free (tips would be appreciated)
