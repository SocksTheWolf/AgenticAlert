Firefox

You can install an optimized web-extension for Firefox based browsers (Librewolf, Waterfox, Zen, etc) from the Mozilla Addons store.

Be sure to allow all permissions and for the latest rulesets, turn on auto-updates!

Chrome (manifest v3)

Chrominium browsers that support manifest V3 can install from the Chrome webstore.

Most Chrominium browsers support V3 already, here's a (not conclusive) list of them:

  • Vivaldi
  • Helium
  • DDG
  • Otter
  • Edge
  • Opera

If your Chrome browser does not support V3, use the "Other Browsers" option below.
